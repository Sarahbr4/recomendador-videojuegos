RECOMENDADOR DE VIDEOJUEGOS - PWA

Archivos:
- index.html: aplicación
- manifest.webmanifest: instalación como app
- sw.js: funcionamiento PWA/offline
- icon.svg: icono

Para usarla como app:
1. Sube estos archivos a un hosting que sirva HTTPS (por ejemplo GitHub Pages).
2. Abre la dirección en el móvil.
3. Usa "Añadir a pantalla de inicio" desde el navegador.

La biblioteca inicial está basada en la lista proporcionada por el usuario. La app guarda los nuevos juegos en el almacenamiento local del navegador.
